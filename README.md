# MTUOC-LLM-Lite — OmegaT Machine Translation Plugin

## Català

Connector de traducció automàtica per a **OmegaT 6.x** que permet connectar-se a qualsevol servidor compatible amb l'API d'OpenAI, com ara un proxy **LiteLLM**, **Ollama** o **vLLM**.

### Característiques
- Detecció dinàmica de models disponibles mitjançant l'endpoint `/v1/models`.
- Botó integrat **Test Connection** per verificar la connexió i la latència.
- Control configurable de la **Temperature** (`0.0` – `2.0`) i del nivell de raonament (**Reasoning Effort**: `none`, `default`, `low`, `medium`, `high`) per accelerar els models amb capacitat de raonament (com Qwen 3 o DeepSeek).
- Plantilles personalitzables per al *System Prompt* i el *User Prompt* amb les variables `{source_lang}`, `{target_lang}` i `{text}`.
- Eliminació automàtica dels blocs `<think>...</think>` si el model en genera.

### Instal·lació

1. Descarregueu l'última versió del fitxer `.jar` del connector (`MTUOC-LLM-Lite-20261127.jar`) des de la secció **[Releases](../../releases)** d'aquest repositori.
2. Copieu el fitxer `.jar` a la carpeta `plugins` de la vostra instal·lació d'OmegaT:
   - **macOS:** `~/Library/Preferences/OmegaT/plugins/` *(o bé `~/.omegat/plugins/`)*
   - **Linux:** `~/.omegat/plugins/`
   - **Windows:** `%APPDATA%\OmegaT\plugins\`
3. Reinicieu OmegaT perquè carregui el connector.

### Configuració a OmegaT

1. Obriu OmegaT i aneu a **Preferències → Traducció automàtica** (*Preferences → Machine Translation*).
2. Activeu la casella **MTUOC-LLM-Lite** i feu clic al botó **Configura** (*Configure*).

<img width="450" height="300" alt="image" src="https://github.com/user-attachments/assets/f699309b-46a4-4cde-933d-05e781fdb47d" />


3. Ompliu els paràmetres del servidor:
   - **Server Base URL (/v1):** Adreça del servidor acabada en `/v1` (per exemple, `http://localhost:8004/v1`).
   - **API Key (Bearer):** Clau d'accés configurada al servidor (o `EMPTY` si no en requereix).
   - **Model:** Premeu **Refresh Models** per obtenir la llista de models del servidor i seleccioneu el que vulgueu utilitzar.
   - **Temperature:** Ajusteu la creativitat/aleatorietat del model (es recomana `0.10` per a traducció).
   - **Reasoning Effort:** Seleccioneu `none` per desactivar el raonament intern en models compatibles (com `qwen3.8`) i obtenir respostes gairebé instantànies, o trieu el nivell desitjat (`low`, `medium`, `high`, `default`).
   - **System Prompt / User Prompt:** Podeu deixar els valors per defecte o adaptar les instruccions de traducció.
4. Premeu **Test Connection** per comprovar que el servidor respon correctament i feu clic a **OK** per desar els canvis.

## English

Machine translation plugin for **OmegaT 6.x** that connects to any OpenAI-compatible API endpoint, such as a **LiteLLM** proxy, **Ollama**, or **vLLM**.

### Features
- Dynamic model discovery via the `/v1/models` endpoint.
- Built-in **Test Connection** button to verify connectivity and latency.
- Configurable **Temperature** (`0.0` – `2.0`) and **Reasoning Effort** (`none`, `default`, `low`, `medium`, `high`) to speed up reasoning-capable models (such as Qwen 3 or DeepSeek).
- Customizable *System Prompt* and *User Prompt* templates supporting `{source_lang}`, `{target_lang}`, and `{text}` placeholders.
- Automatic stripping of `<think>...</think>` blocks if generated by the model.

### Installation

1. Download the latest plugin `.jar` file (`MTUOC-LLM-Lite-20261127.jar`) from the **[Releases](../../releases)** section of this repository.
2. Copy the `.jar` file to your OmegaT `plugins` directory:
   - **macOS:** `~/Library/Preferences/OmegaT/plugins/` *(or `~/.omegat/plugins/`)*
   - **Linux:** `~/.omegat/plugins/`
   - **Windows:** `%APPDATA%\OmegaT\plugins\`
3. Restart OmegaT to load the plugin.

### Configuration in OmegaT

1. Open OmegaT and go to **Preferences → Machine Translation**.
2. Check the **MTUOC-LLM-Lite** box and click **Configure**.

<img width="450" height="300" alt="image" src="https://github.com/user-attachments/assets/b2f25448-807b-4362-a417-c1d03343fabd" />

3. Fill in the server parameters:
   - **Server Base URL (/v1):** Server endpoint URL ending in `/v1` (e.g., `http://localhost:8004/v1`).
   - **API Key (Bearer):** Access key configured on the server (or `EMPTY` if none is required).
   - **Model:** Click **Refresh Models** to fetch available models from the server and select the desired one.
   - **Temperature:** Adjust model randomness/creativity (`0.10` is recommended for translation).
   - **Reasoning Effort:** Select `none` to disable internal reasoning on compatible models (such as `qwen3.8`) for near-instant responses, or choose the desired level (`low`, `medium`, `high`, `default`).
   - **System Prompt / User Prompt:** Keep the default templates or customize the translation instructions.
4. Click **Test Connection** to verify that the server responds properly and click **OK** to save your settings.

<img width="450" height="300" alt="image" src="https://github.com/user-attachments/assets/1d778ce5-1f1c-4809-a0c2-90e15623b98a" />


The compiled `.jar` file will be generated at `build/libs/MTUOC-LLM-Lite-20261127.jar`.
